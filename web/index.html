How to interact

  • Rotate: click and drag on the canvas
  • Zoom: mouse wheel (or W / S when focused)
  • Pan camera: A D R F
  • Move target: J K O L
  • Models: use the dropdown above (keyboard 1–5 still works)
  • Render modes: use the dropdown (F1–F4 on desktop)

About

This is a from-scratch CPU rasterizer written in C++: perspective projection, depth buffering, back-face culling, OBJ/MTL loading, and wireframe, flat, Gouraud, and Phong shading. The demo runs in the browser via Emscripten and SDL3.
